JAVA

Het politieke en economische hart van Indonesië

Over Java

Java is het dichtstbevolkte eiland van Indonesië en speelt een belangrijke rol in de economie en politiek van het land. De hoofdstad Jakarta ligt op Java en het eiland heeft een rijke geschiedenis en cultuur.

Bezienswaardigheden

Bekende plekken op Java zijn de tempel Borobudur, de Prambanan tempels en de actieve vulkaan Mount Bromo. Het eiland heeft ook grote steden zoals Jakarta en Yogyakarta met veel cultuur en geschiedenis.

Natuur en Landschap

Java heeft een indrukwekkend landschap met vulkanen, rijstvelden en regenwouden. De vruchtbare grond maakt het eiland belangrijk voor landbouw en voedselproductie.

Locatie van Java

Java ligt in het hart van Indonesië en is omringd door de Javazee, de Indische Oceaan en de Bali-zee. Het eiland heeft een strategische ligging en is een belangrijk knooppunt voor handel en transport in de regio. In de kaart hieronder zijn locaties van een aantal grote tempels op Java weergegeven.
